# Drowned Library
A personal project, drownedlibrary.org is a not for profit website built for the purposes of bringing an interactive poetry discovery experience in a world swallowed by the sea. Sail the submerged globe, fish for forgotten verses and preserve them in your journal. Explore a drowned library of what the water could not erase.

A calm, single-page poetry discovery game. Sail a drowned world, cast a line, and raise poems from the water.

The whole site is one file, index.html. It loads three.js and pako from cdnjs and the Fraunces font from Google Fonts, and keeps each visitor's progress in their own browser.

To update the site, replace index.html in this repository and commit. GitHub Pages republishes it within a minute or two.

Submissions or requests go to librarian@drownedlibrary.org.
